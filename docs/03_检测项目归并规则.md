# 检测项目归并规则

## 0. 第一规则：繁体先转简体

- 报告出现繁体文字时，必须先将全文转换为简体，再进行表头、字段、检测项、结果和元数据识别；繁体原文另行保留用于追溯。

## 1. 基本原则

- 按检测含义归并，不按字面机械改名。
- 不同检测机构对同一指标的轻微命名差异归为同一标准项目。
- 会改变指标含义的测试条件、部位、介质或方向保留为子项或实测描述。
- 机构原名称合理时不做多余改写。
- `抗起毛球`保留为`抗起毛球`，不改为`起毛起球`。
- `pH值`、`pH值（其他）`、`pH值(其他)`、`PH值`统一归为`pH值`。
- 横向汇总只使用“统一检测父项”作为列名；酸汗/碱汗、干摩/湿摩、材料、方向、洗前/洗后、组分和具体化学物质写入同一父项单元格内的子项，不再各占一列。
- `质检全项目明细`保留原始检测项、归并前标准项、统一检测父项及标准检测子项，保证归并后仍可追溯。
- 既有人工确认的`确认后统一名称`作为规则种子；本文件中较新的明确规则优先，例如`标识标签*`、`标识标签`、`标识`统一为`标识标签`。
- 归并依据是检测项在报告中的结构和语义角色，不维护“某几个短词永远不能成为父项”的封闭黑名单。同一词在不同上下文中可以是父项或子项。
- 已能确定检测领域或父项、但具体子项类型无法完全恢复时，允许自动归入已确定的父项，标准子项写为`具体类型未识别`并保留原始名称、证据和置信度；不再逐条要求人工确认。
- 只有无法确定检测领域或父项的完整记录才标记`待确认归属`；明显的页眉页脚、说明句、断句和OCR残片标记为`解析残片`并排除，不作为检测父项。

### 1.1 父项与子项的通用判断

归并先恢复报告结构，再判断名称相似度。证据优先级如下：

1. PDF表格合并单元格或同一检测块中明确的父项；
2. 同页编号检测章节、上一完整检测项及跨页延续关系；
3. 检测方法或标准号指向的检测领域；
4. 名称语义角色；
5. 单位、标准要求和结果形态。

父项应能独立回答“检测什么”。依赖上文才能表达完整含义的文本，按其语义角色作为子项保留，例如测试条件、材料、方向、部位、层次、组分、具体物质、评级维度或结果维度。这里的例子仅用于解释角色，不构成固定词表；以后出现新的材料、方向、条件或组分，仍按相同规则判断。

例如，`棉`在色牢度表格中可能是贴衬材料，应作为色牢度父项的子项；`棉纤维含量`本身能完整表达检测对象，则应归入`纤维含量`。系统不能因为名称中出现`棉`就机械排除其成为父项。

### 1.2 自动归并置信度

- 结构证据：50分；
- 检测方法或标准号：30分；
- 名称语义角色：15分；
- 单位、标准要求或结果形态：5分。

处理原则：

- 80分及以上：自动归入确定父项和子项；
- 60至79分：父项确定且原始子项完整时保留原始子项并标记`自动归并（中置信度）`；只有子项也无法完整恢复时才写`具体类型未识别`；
- 名称完整、检测对象明确但现有项目库没有对应项：自动新增规范化父项，状态记为`自动新增`；
- 无法确定检测领域或父项：才进入`待确认归属`；
- 明显解析残片：标记`解析残片`并排除，不进入横向正式列。

人工复核的目标是确认或调整一条通用规则、机构版式规则或标准号规则，而不是逐行确认同类记录。

### 1.3 名称前置标准化与无语义符号清洗

检测项归并必须先完成名称前置标准化，再判断父项和子项。不得先按连字符、括号或字面名称拆分，再补做符号清洗。统一处理顺序如下：

1. 报告全文先转为简体识别副本，原始繁体文本保留在原始行、页面原文或诊断字段。
2. 对简体识别副本执行Unicode兼容规范化，统一全角/半角字母、数字、百分号、空格及等价标点。
3. 识别并删除名称开头和结尾的无语义字符，包括常见项目符号、PDF字体私用区字符、控制字符、不可见字符以及连续标点。不得仅维护`■`、`●`、`▪`等有限符号名单。
4. 统一中文圆括号、英文圆括号、方括号及全角方括号的结构表达，再提取括号内容。
5. 括号内容是单位时，从检测项名称中移除，写入单位字段；括号内容是材料、部位、方向、层次、测试条件或具体组分时，作为标准子项保留。
6. 完成上述处理后，再按检测语义核心归并机构用词差异，例如`鉴别`与`鉴定`在检测对象一致时视为同义动作词。
7. 最后根据报告结构、检测标准、名称语义和结果形态确定父项；只含符号、标点或不可见字符的内容不得成为父项、不得进入横向主表。

对于CTTC等无网格文本定位版式，必须先恢复逻辑列，再进入父项/子项拆分。若PDF没有可用网格线，解析器应根据表头、字段坐标、行高和结果/判定列位置恢复“检测项目、标准要求、实测结果、单项判定”等逻辑列；同一检测项单元格内因文字定位被拆散的片段应连续拼接，例如`可分`、`解致癌芳香`、`胺染`、`料`必须先还原为`可分解致癌芳香胺染料`。只有在完整检测项和上下文恢复后，才允许添加真正的父项与子项分隔符，例如`酚黄变-黄变级数`；不得用连字符连接同一词语内部的定位碎片。

括号内容分类不得只依赖固定词表，应同时参考字符形态、单位字段、检测方法、结果形态和上下文。例如：

- `残脂率`、`残脂率(%)`、`残脂率(％)`统一为父项`残脂率`，`%`写入单位字段，不作为子项。
- `材质鉴别[帮面]`、`材质鉴定（帮面）`统一归入父项`材质鉴定`，`帮面`作为部位子项保留。
- PDF提取出的`U+F0A2`等私用区项目符号必须删除；`U+F0A2-二氨基二苯甲烷`应归入父项`可分解致癌芳香胺染料`，子项为`二氨基二苯甲烷`，不得将符号作为父项。

名称清洗和验收不得使用同一份有限符号枚举。验收必须独立检查Unicode私用区字符、控制字符、不可见字符、纯标点父项和缺少语义文字的父项，防止清洗规则与质量检查同时漏检。

## 4. 色牢度专项归并规则

色牢度优先归入能够由报告结构、检测标准或上下文确定的具体父项，例如：

1. 耐皂洗色牢度
2. 耐水色牢度
3. 耐汗渍色牢度（酸汗、碱汗）
4. 耐唾液色牢度
5. 耐摩擦色牢度

归并要求：

- `干摩`、`干摩擦`、`湿摩`、`湿摩擦`、`耐干摩擦色牢度`、`耐湿摩擦色牢度`统一归为`耐摩擦色牢度`，干/湿作为子项或结果描述保留。
- `酸汗`、`碱汗`、`耐酸汗渍色牢度`、`耐碱汗渍色牢度`统一归为`耐汗渍色牢度`，酸汗/碱汗作为子项或结果描述保留。
- `GB/T 5713`、`耐水`相关色牢度统一归为`耐水色牢度`。
- `GB/T 3921`、`皂洗`、`耐洗`相关色牢度统一归为`耐皂洗色牢度`。
- `耐唾液`相关色牢度统一归为`耐唾液色牢度`。
- `变色`、`沾色`、贴衬纤维名称、颜色名只作为色牢度项目下的子项或实测结果，不作为独立统一检测项。
- 能确定属于色牢度领域、但无法从项目名称、检测方法或上下文恢复具体色牢度类型时，统一父项可暂记为`色牢度`，标准子项写`具体类型未识别-原始子项`。`沾色`、`变色`及贴衬材料不得独立成为横向父项。
- 上述具体父项是当前常见类型，不是封闭清单；后续出现新的完整色牢度检测类型时，按通用规则自动新增父项。

## 5. 子项保留

以下差异不应直接覆盖，应在子项或结果描述中保留：

- 酸性与碱性汗液
- 干摩与湿摩
- 变色与不同贴衬纤维沾色
- 经向与纬向
- 不同温度、时间、循环次数
- 不同样品部位或材料层

### 5.1 羽绒成分测定必须保留的完整子项

`2026Q4`产品中的羽绒成分属于重点数据。报告使用合并单元格时，以`羽绒成分测定`为父项，逐行继承并生成以下完整检测项：

1. `羽绒成分测定-含绒量`
2. `羽绒成分测定-含绒量极限偏差`
3. `羽绒成分测定-绒子含量`
4. `羽绒成分测定-长毛片含量`
5. `羽绒成分测定-异色毛绒`
6. `羽绒成分测定-绒丝+羽丝`
7. `羽绒成分测定-杂质`
8. `羽绒成分测定-陆禽毛`

相邻的`蓬松度`、`浊度`、`水分率`、`残脂率`、`耗氧量`、`气味`、`羽毛羽绒品种`为独立检测项，不并入`羽绒成分测定`。

完整性约束：

- 不允许输出单独的`含绒量`、`绒子含量`、`杂质`等子项作为正式标准检测项。
- 不允许把上述8个子项压缩成一个`羽绒成分测定`结果。
- 项名中的`含量`、`极限偏差`、`毛片`、`毛绒`、`绒丝+羽丝`等语义不得被截断或相互替换。
- OCR结果若无法确认父项或子项的完整边界，该行进入`项名不完整待复核`，不以短词进入汇总。

## 6. 待确认处理

只有以下情况才标记“待确认”或写入`质检全项目明细`异常记录：

- 名称相似但可能代表不同指标。
- 报告文本残缺，无法确认项目含义。
- OCR或文本提取导致名称错乱。
- 新机构术语既无法从报告结构、标准号、上下文和语义角色确定领域，也不能作为名称完整的新检测项自动新增。

## 7. 新检测项扩展

- 解析到原有规则未覆盖的检测项时，不得丢弃。
- 名称完整、检测对象明确的新检测项应写入`质检全项目明细`，以规范化简体名称自动新增父项，状态标记为`自动新增`，不要求逐条人工确认。
- 只有名称不完整或检测含义仍不明确的新项才进入`质检全项目明细`异常记录，并保留货号、颜色、源报告单号、PDF报告号、PDF链接、原始检测项和上下文详情。
- 人工确认后，新增检测项应加入标准检测项清单或作为既有标准项的别名，不应只作为一次性修正。
- 新增归并规则必须保留原始名称、简体名称、统一名称、归并说明和首次出现来源，便于后续审计。

## 9. 面料/部位差异与检测结果细则

部分检测项会因面料、部位、颜色组合或样品层不同，在检测项目名称后用括号、方括号等方式列出多个子项。归并时应保留这些差异，但不应默认把它们拆成多个标准检测项目。

归并原则：
- 同类项归并只用于解决不同检测机构对同一检测含义的轻微命名差异，不用于吞并检测细项。
- 不同细项必须明确分开保留；例如`耐水色牢度-变色`、`耐水色牢度-沾色[棉]`、`耐水色牢度-沾色[锦纶]`横向统一使用父项`耐水色牢度`，但分别保留为不同标准子项，不能丢失或互相覆盖。
- 不因括号内容不同而直接拆成多个标准检测项目，除非括号内容代表面料、部位、颜色组合或样品层等检测子项；这类内容应作为细项保留。
- 标准检测项目优先保留核心名称；括号、方括号中的面料、部位、颜色组合进入`检测项目细则`或`检测结果细则`。
- 每个细则必须保留对应`检测结果`和`单项判定`，不能只保留汇总判定。
- 同类项人工判断以完整检测含义判断是否归并；短词、截断词或孤立子项不得直接进入正式归并规则，应回溯 PDF 表格父级项目后再判断。
- 归并前必须清洗无意义符号：单独的`/`、`-`、`—`、空括号、尾部半个括号、前导逗号/顿号、项目符号`●/•/·/▪/■`不能作为候选项、父项或细项；这类符号只能作为分隔符或直接删除。
- 归并前必须做繁简复核：常见繁体字应先转换为简体；仍残留繁体字、繁简混写或机构专有繁体写法时，输出到复核清单，人工确认后再写入稳定规则。
- 人工确认后，稳定细则可升级为固定子项规则，但仍要保留原始 PDF 链接和原始检测项目单元格。
